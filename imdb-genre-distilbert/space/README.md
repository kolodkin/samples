# IMDb Plot → Genre Classifier

Gradio demo for [`kolodkin/imdb-genre-distilbert`](https://huggingface.co/kolodkin/imdb-genre-distilbert) — a DistilBERT fine-tune that predicts movie/show genres from plot text. Trained on [`kolodkin/imdb-wikipedia-enriched`](https://huggingface.co/datasets/kolodkin/imdb-wikipedia-enriched).

Source: https://github.com/kolodkin/samples/tree/main/imdb-genre-distilbert
